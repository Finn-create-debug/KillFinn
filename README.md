# 基于图像处理的 FPGA 仿真验证平台（题目三）

一个纯 Verilog 的 FPGA 图像处理仿真平台：**图片 → 写入 RAM → 读像素处理 → 写回 RAM → 输出 BMP**，多种算法在 testbench 中通过**宏定义**切换，全部算法与独立黄金模型逐像素比对验证通过。

> 零依赖：图像转换、逐像素校验全部用系统自带 PowerShell 完成，不需要 Python。
> 环境：Vivado 2026.1（xsim 仿真），器件 xc7a35tfgg484-2。

---

## 一、总体架构（三层模块）

```
tb_img.v(testbench)        img_core.v(数据通路)         img_algo.v(算法)
───────────────────────    ─────────────────────────    ─────────────────
读 BMP → 写 in_ram   ──►   in_ram[16384]×24bit    ──►   3×3 邻域窗口
复位 / start 控制     ──►   3×3 窗口生成器(FSM)    ──►   ┌ 点运算(用中心 w_c)
wait(done)            ◄──   out_ram[16384]×24bit   ◄──   └ 邻域运算(9个)+缩放+梯形
读回 → 写 .mem → BMP
```

| 模块 | 职责 |
|------|------|
| `rtl/img_core.v` | 两块 24bit RAM、3×3 窗口生成状态机、读延迟对齐、边界钳位、缩放坐标映射 |
| `rtl/img_algo.v` | 纯组合逻辑，按宏选择算法，输出 `pix_out`（结果）与 `hit`（目标命中） |
| `sim/tb_img.v` | testbench：写图 → 启动 → 等 done → 读回存文件 |
| `sim/algo_cfg.vh` | ★ 算法宏开关（题目要求"testbench 中宏定义选择"） |

## 二、核心思路：从"读一个像素"到"造出 3×3 窗口"

### 难点

膨胀/腐蚀/锐化都要看"当前像素 + 上下左右"共 **9 个邻居**，而板上 BRAM 只有 **1 个读端口**、且读数据还要**晚 1 拍**。所以必须先想办法凑出一个 3×3 窗口，算法才能看到邻居。

### 解法：窗口生成器，一个像素 12 拍

```
第 1~9 拍：依次发 9 个读地址，数据回来存进 win[0] ~ win[8]
第 10 拍：9 个数据到齐
第 11 拍：img_algo 组合逻辑算出结果，写回 out_ram
第 12 拍：换下一个输出像素
```

窗口与算法端口的对应关系：

```
win0=左上  win1=上   win2=右上
win3=左    win4=中心 win5=右        ← w_c 是中心像素
win6=左下  win7=下   win8=右下
```

点运算只用中心 `w_c`；膨胀/腐蚀/锐化用全部 9 个；缩放/梯形只改坐标映射。

### 两个最容易出错的地方

1. **读延迟 1 拍的对齐**：BRAM 是"本拍给地址、下拍出数据"，所以数据到达时地址已经变了。用 `kq`（延迟后的读序号）标记"这一拍回来的数据是第几个邻居"，否则窗口 9 个格子会整体错位一个像素。
2. **边界钳位**：边缘像素的 `cx±1 / cy±1` 越界时钳到 `0` 或 `W-1/H-1`（复制边缘像素）。这样**每个输出像素都有合法的 3×3 邻域**，画面不会出现黑边，也不需要特殊分支。

### 取舍

一个像素 12 拍，128×128 全图约 20 万拍 ≈ 2.5 ms 仿真。用仿真速度换逻辑清晰；要实时可改成"2 行缓存 + 3 位移位寄存器"的流水线（1 拍 1 像素），代价是边界处理和行计数复杂得多。

## 三、13 种算法详解

### 第 1 类：点运算（6 种，只用中心像素 w_c）

| # | 宏 | 算法 | 公式 / 规则 |
|---|----|------|------------|
| 1 | `ALGO_INVERT` | 反色 | `255 − x` |
| 2 | `ALGO_GRAY` | 灰度化 | `Y = (77R + 150G + 29B) >> 8` |
| 3 | `ALGO_BINARIZE` | 二值化 | `Y > 128 ? 白 : 黑` |
| 4 | `ALGO_RGB_SWAP` | 通道交换 | `{R,G,B} → {B,G,R}` |
| 5 | `ALGO_BRIGHT` | 亮度增强 | 三通道饱和加 60 |
| 6 | `ALGO_RED_DETECT` | 红色识别 | `R>150 && G<100 && B<100 && R>G+60 && R>B+60` |

- 灰度系数 **77 / 150 / 29** 是 BT.601 亮度（0.299 / 0.587 / 0.114 ×256）的 8bit 定点近似，用"乘 + 右移 8"实现，**全程无浮点**。
- 红色判据的教训：初版只判相对色差（R 比 G、B 大），把右上角橙红渐变误检成红色、命中 4608 像素；收紧到"绝对亮度（R>150）+ 相对色差（R 比 G、B 都大 60）"双重约束后，命中 2337 且不再误检。**颜色识别必须同时约束绝对亮度与相对色差**。

### 第 2 类：3×3 邻域 / 缩放 / 梯形（7 种）

| # | 宏 | 算法 | 原理 |
|---|----|------|------|
| 7 | `ALGO_DILATE` | 膨胀 | 3×3 灰度取最大 → 亮区变胖、暗孔被填 |
| 8 | `ALGO_ERODE` | 腐蚀 | 3×3 灰度取最小 → 亮区变瘦、暗细节扩大 |
| 9 | `ALGO_SHARPEN` | 锐化 | 拉普拉斯高通叠加回原图 |
| 10 | `ALGO_SCALE_UP2` | 放大 2 倍 | 源坐标 = 输出坐标 `>> 1`（最近邻） |
| 11 | `ALGO_SCALE_DOWN2` | 缩小 2 倍（抗混叠） | 2×2 平均 = 低通后再抽样 |
| 12 | `ALGO_SCALE_DOWN2_ALIAS` | 缩小 2 倍（直接抽样） | 直接隔点抽样，故意制造混叠用于对比 |
| 13 | `ALGO_TRAPEZOID` | 梯形校正 | 仿射反向映射 + 水平双线性插值 |

- **锐化（拉普拉斯核 `[0 -1 0; -1 5 -1; 0 -1 0]`）**：`lap1 = c×5 + 1024 − up − dn − lf − rt`，再钳位到 `[0,255]`。`+1024` 偏移把有符号运算变无符号，避免用 `signed` 类型。
- **缩放不另写模块，只改坐标映射**：放大 `cx = ox>>1`、缩小 `cx = ox<<1`，复用同一套窗口逻辑。缩小 2 倍时中心映射到 `(2ox, 2oy)`，正好让 `w_c/w_r/w_b/w_br` 就是待平均的那个 2×2 块。
- **混叠对比**：同样缩小 2 倍，`DOWN2` 先 2×2 平均（低通）再抽样无摩尔纹；`DOWN2_ALIAS` 直接抽样，高频折返产生混叠。两张并列就是"抗混叠"最直观的演示。
- **梯形校正**：反向映射（顶部窄、底部宽的梯形），水平方向做双线性插值 `pixel = ((128−f)·src[cx0] + f·src[cx0+1]) >> 7`，`f` 为 7bit 插值小数（`f/128`）。

## 四、关键设计要点（答辩会被问）

- **为什么两块 RAM**：`in_ram` 只存输入、`out_ram` 只存输出，避免同一块 RAM 边读边写冲突，也方便后续流水线。
- **为什么一个像素 12 拍**：单读端口读 9 个邻居就要 9 拍，再加等数据、写回、换像素。用仿真速度换逻辑清晰。
- **读延迟 1 拍怎么对齐**：窗口寄存器用 `kq`（延迟后的读序号）标记"这拍回来的数据是第几个邻居"，否则 9 个格子整体错位。
- **全程定点无浮点**：灰度、双线性插值都用"乘 + 右移"，不引入浮点 IP。
- **为什么输出走 .mem 中转**：仿真器写二进制 BMP 易受 CRLF/EOF 干扰，写成十六进制文本再由脚本转 BMP 最稳。
- **上电清零 + 异步复位**：RAM、窗口寄存器 `win[0..8]`、读/写流水线、状态机全部复位，波形看不到 X。

## 五、验证方法（写报告的证据）

独立的 PowerShell 黄金模型 `verify_algo.ps1` 把 RTL 逻辑**重写一遍**（窗口钳位、灰度公式、拉普拉斯钳位、2×2 平均、双线性插值……），逐像素比对：

```
[verify] 算法 ALGO_DILATE   输入 128x128 -> 输出 128x128 (16384 像素)
[verify] 不匹配 0 / 16384  —— 完全一致
```

**13 种算法全部 0 不匹配**（放大 2 倍 0/65536、缩小 0/4096、其余 0/16384）。这一步证明"算法实现是对的"，而不是"看图差不多"。

## 六、运行方法

```powershell
cd E:\FPGA\img_proc_sim
.\run_sim.ps1 -Algo ALGO_DILATE -Verify   # 跑某个算法并逐像素校验
```

两种切算法方式：

- **方式 A（题目要求）**：改 `sim\algo_cfg.vh`，把要用的那一行取消注释，其余保持注释。
- **方式 B（命令行）**：`-Algo 算法名`，编译时用 `-d` 宏覆盖，优先级更高。
